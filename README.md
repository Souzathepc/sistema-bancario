# Sistema Bancário

Sistema bancário simples no terminal, feito em Java para praticar lógica de programação e orientação a objetos.

> 🚧 Projeto em desenvolvimento

## Funcionalidades

- [x] Menu interativo com repetição
- [x] Consultar saldo
- [ ] Depositar
- [ ] Sacar
- [ ] Transferir

## Como rodar

1. Clone o repositório
2. Abra no IntelliJ IDEA
3. Rode a classe `SistemaBancario`
